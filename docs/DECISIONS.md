# Decisions

One line per decision: **decision** — reason.

- **Flutter 3.47.9 stable pinned in CI** — reproducible builds; bump deliberately.
- **Riverpod (flutter_riverpod 3.x) for app-wide state; ChangeNotifier for the per-match controller** — compile-safe providers for meta/settings; the controller is screen-scoped and awaited by the scene.
- **very_good_analysis lints, minus `public_member_api_docs`, 80-col, `no_default_cases`, `unnecessary_type_name_in_constructor`, `unnecessary_unawaited`** — strict but practical; the last two interact badly with `dart fix` in 3.13.
- **Application id `com.haftnard.game`, minSdk 23** — matches spec; neutral id.
- **CI signing: secrets → cached CI keystore → freshly generated keystore** — never fails without secrets; cached key keeps upgrades installable most of the time.
- **Release builds use R8 minify + resource shrinking** — smaller APK.
- **Board representation: two 26-slot arrays in each side's own frame (0 = off, 25 = bar)** — move generation never branches on colour; absolute numbering (White's home 1–6) only for UI and effects.
- **Moves are recorded in the mover's frame with the die used** — unambiguous, compact, server-verifiable.
- **Seven Event: one `p7` check per turn on the first roll only (base 1/36); bonus rolls/rerolls never trigger it** — a 7–7 never wastes a turn and can't chain; matches "same odds as a specific double".
- **After a 7–7 the player rolls normally in the same turn** — spec: 7–7 never wastes a turn.
- **No 7–7 on the opening roll** — keeps the classic opening intact.
- **Cards without valid targets are excluded from offers; if one fizzles anyway it is consumed** — no dead picks.
- **Rarity weights 60/28/10/2 with pity (+3 epic, +1 legendary weight per offer without epic+)** — bad-luck protection.
- **Unlisted card rarities default to Common** — spec lists rarities only for some cards.
- **Effect durations count the affected side's turns** — "for 2 of their turns" reads naturally; shields protect for 3 opponent turns.
- **Holy Shield follows its checker; Iron Gate is anchored to its point** — differentiates two similar cards.
- **Ghost Step = a blocked landing glides to the next open point beyond** — "jump over/land past a blocked point".
- **Toll Gate = crossing (strictly) costs one extra pip per toll** — simple, deterministic, composable with bear-off.
- **Blood Pact (not home) sends the *most advanced* checker to the bar** — the drawback must hurt.
- **Mirror copies the opponent's next roll as a bonus roll at the start of your following turn (played after your normal roll)** — clear timing.
- **Time Stop drawback = opponent picks one extra card at their next 7–7; Greed drawback = opponent's next offer shows one extra card** — risk/reward without new systems.
- **Phoenix re-enters at the most advanced open point of the opponent's home** — "instantly for free" with a deterministic rule.
- **Thief with nothing to steal grants a reroll token** — never a dead card.
- **Hidden landmines: the AI plans without knowing them and replans if legality changes** — fairness; pass-and-play shows mines only on the owner's turn.
- **Backgammon (Kup Mars) = loser has borne off nothing and has a checker on the bar or in the winner's home** — standard rule.
- **Crawford game only when the cube is enabled** — cube is off by default (Persian tavla).
- **Undo is controller-side (state stack per roll) and removes the action from the log** — the engine stays a pure function; logs only contain committed moves.
- **Human must press Done after moving (undo window); auto-pass only when no move and no reroll/lucky/fate is available; forced single plays auto-play when enabled** — spec "undo before confirming" + "auto-move option".
- **AI tiers: Beginner (40% random + noise), Easy/Medium (1-ply, noise), Hard (2-ply top-5), Master (2-ply top-9) with Star1-style cutoffs** — strong enough, < ~1 s per move on device in an isolate.
- **Board aspect adapts (0.92–1.18) to the viewport** — bigger touch columns in portrait.
- **Point touch targets are full half-height columns** — narrower than 48dp on small phones (inherent to 24 points) but tall; drag-and-drop and "tap source again to play the larger die" mitigate.
- **Cosmetics, cards and talismans carry fa/en text in Dart data, UI chrome uses ARB** — keeps game data testable in pure Dart.
- **Persian digits via `NumberFormat.decimalPattern('fa')` and a helper for custom strings** — natural Persian UI.
- **Journey: 8 stages (2+boss, 2+boss, 1+final boss), all single-point matches** — ~30–45 min runs on mobile.
- **Journey keeps 40% of run coins on loss (100% on win) + 20/stage + 300 completion bonus** — losing still progresses.
- **Fonts: Vazirmatn (static weights), Lalezar (display, fa+latin), Cinzel Decorative (latin logo), all OFL with licenses bundled** — spec.
- **All audio synthesized by `tool/gen_sfx.dart` (22 kHz mono WAV, ~1 MB total)** — no downloads, deterministic.
- **Music: an 8-second synthesized drone + santur-like plucks loop** — ambient without assets.
- **`dart fix --apply` is not used blindly** — it mangled `unawaited()` calls once (see commit history).
- **Balance pass 1 (forced-pick sim): all 24 starter cards ≤ +8% lift/pick; Toll Gate 4→5 turns (weakest common)** — see docs/balance/report.md.

- **Audio rebuilt around `AudioManager` (lib/game/audio/).** Each sound has a fixed set of preloaded low-latency voices, created once. Plays obey a per-sound/group cap (clacks max 3), a global cap of 8 with oldest-voice stealing, and a debounce window. Every platform call has a 600 ms timeout, and 3 failures within 5 s rebuild all players (watchdog). Audio stops in the background and is fully rebuilt on resume. Sound effects and music no longer request Android audio focus: audioplayers' default (`gain` on every player) let effects steal focus from the music and from each other, the likely cause of the mid-match breakage. A single failure no longer disables audio for the session. flame_audio is dropped (audioplayers used directly). Covered by a 20,000-play stress test plus watchdog, hang, lifecycle and dispose tests.

Stack re-layout nudges also counted as "moving", so the stack under a landing checker repainted above it. Re-layout nudges no longer count as travel. A regression test drives a real AI match through the Flame scene and checks the order every frame; it fails with the old ordering.

- **Double Seven odds live in `lib/core/rules/seven_odds.dart`: a 5% base per own turn, flat for the first 9 dry turns, then a steep ramp; the 12th dry own turn in a row is certain.** Card and talisman multipliers scale the result; Seven Block still forces 0; Classic never rolls 7–7. - **Dice:**

- **Memory, exact cause:** in debug builds Riverpod 3's devtools recorder (`RiverpodDevtool.frames`, a static list) keeps every provider event forever, including each disposed ProviderContainer and every state snapshot, so every finished match's save data stayed reachable.
  - Release builds never record (the observer is debug-only), so the phone APK was not affected by it.

  - Most of the earlier "~4 MB/match RSS" was lazy GC in flutter_tester. With forced full GCs the heap is flat apart from JIT code.
  - The soak test now runs with the VM service. It forces full GCs and asserts at most 2 live SaveService/ProviderContainer and 1 MatchController after 50 matches. Growth in Dart objects from match 5 to match 50 must stay under 5 MB (measured: +2.7 MB, about 60 KB per match); VM-internal JIT code (Code, Instructions, Function…) is not counted because an AOT release build doesn't have it.
  - **Second cause (tests only):** `HapticFeedback.*` goes over `flutter/platform`, and flutter_tester never answers. Each haptic left a pending future, with its whole stack_trace chain, in `TestDefaultBinaryMessenger._pendingMessages`: about 250 per match, roughly 1.5 MB/match. `test/flutter_test_config.dart` now answers that channel the way a device does. With the fix, retained stack traces dropped from 14,842 to 133.
  - Each soak match is now its own `testWidgets`. `flutter test` always passes `--chain-stack-traces`, so one long async test body grows a chain without bound. One shared ProviderContainer (via `UncontrolledProviderScope`) keeps it a single app session.

- **LAN / hotspot multiplayer (no server)** (`lib/net/lan/`):
  - Play → "Friend (Wi-Fi)": one phone taps *Create game* (picking the mode, length and cube as usual) and plays White. The other taps *Join a game* and plays Black.
  - **Transport:** plain TCP between the phones, one JSON object per line (`SocketChannel`). There is no server and no plugin: only `dart:io`, plus the `INTERNET` and `ACCESS_NETWORK_STATE` permissions (release builds had neither).
  - **Discovery, three ways:**
    1. The host broadcasts a UDP beacon every second.
    2. The guest probes every address of its /24 subnets on the game port. This works where broadcast is filtered, which is common on hotspots and on Android without a multicast lock.
    3. The guest can type the address shown on the host's screen (`ip` or `ip:port`).
  - **Sync:** both phones run the same deterministic engine from the host's seed and config, so only actions travel.
    - The local player's moves stay local and undoable until the next non-move action (Done, a roll, a pick…). Then they go out as one batch, with the hash of the state they reached.
    - The receiver replays the batch and checks the hash before showing it. On a mismatch, the host's committed log wins (`need` → `log` → `adoptLog`).
  - **Robustness:**
    - A heartbeat every 2 s; 7 s of silence means the connection is lost. The heartbeat counts silent ping intervals rather than wall-clock time, so it also works under the tests' fake time.
    - The guest retries the host every 2 s, and the host keeps listening during the match. On reconnect, each side resends the committed actions the other is missing.
    - Leaving mid-match sends `bye`, which counts as resigning on the other phone. A different protocol version, or a third phone, is refused with a clear message.
  - **Not covered:** hidden information (landmines) is not hidden from a modified client on LAN; that needs the server plan in `ONLINE_PLAN.md`. A drop exactly across a game boundary is not resent, so the players restart that match.

  - The expected rolls to bear off, with perfect play, for all 54,264 home positions. It is stored as base64 Uint16 (×4096, 145 KB) because the AI runs in a fresh isolate for every move and can't keep a runtime cache. Generating it takes about 16 s.
